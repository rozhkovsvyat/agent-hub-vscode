# Woven Network — черновик бренд-направления

Это не утверждённый rename продукта и не подключённый asset расширения. Здесь проверяется
визуальная метафора: локальная сеть связей, которую плетут агенты вокруг точки маршрутизации.

## Что говорит знак

- **центр** — маршрутизатор и receipt hub: направляет, но не присваивает данные;
- **восемь нитей-основ** — независимые агенты и контуры;
- **разорванные кольца-уток** — общий слой памяти поверх физически раздельных контуров;
- **разрывы** — не дефект: они показывают, что контуры не склеиваются друг с другом напрямую.

## Варианты

- `weft-mark.svg` — монохромный основной знак, `currentColor`, для 24–48px;
- `weft-favicon.svg` — упрощённая версия для 16px;
- `weft-mark-color.svg` — цветной знак для webview и крупных поверхностей;
- `weft-lockup.svg` — демонстрационный lockup с рабочим словом **Weft**.

Слово **Weft не предлагать к закреплению**: на 2026-08-21 поиск нашёл несколько действующих
продуктов Weft, в том числе агентские coding assistants. Оно оставлено в lockup только для
оценки звучания и пропорций. Если направление принимается, нужно отдельно выбрать и проверить
уникальное имя, затем заменить только текст в lockup.

## Приёмка

Знак не содержит треугольника, play-стрелки, буквального паука, градиентов или тонкого штриха.
Все кривые векторные, `viewBox="0 0 64 64". На 16px использовать только favicon-версию.
