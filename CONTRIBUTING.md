# Contributing to Cukii Chat

Thanks for wanting to help.

- **Bugs:** use **Report a bug** inside the chat; it attaches the diagnostics needed to reproduce. A GitHub issue works too.
- **Code:** see [README.md](./README.md) for the layout and the build/test commands. Keep changes small, add a test that fails without the change, and run the GUI and extension test suites before opening a pull request.
- **Security issues:** follow [SECURITY.md](./SECURITY.md), not the public issue tracker.
